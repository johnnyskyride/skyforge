# SkyForge

Analog instrument by [@johnnyskyride](https://x.com/johnnyskyride).

## Offline play

Download **SkyForge.html**. That one file is the whole instrument.

1. Save it to your laptop, phone files, or a USB stick
2. Open it in Chrome, Safari, Firefox, or Edge — even with no internet
3. Click to arm audio, then play the keys (Z–M / Q–P, space to sustain)

No install. No account. Send the file to anyone.

## Ableton

Arm, play a part, hit **Bounce** for a WAV, drop it on a track.

Halloween knobs the haunt. Presets: Init, Bass, Lead, Pad, Pluck, Keys, Haunt.

SF-33.
