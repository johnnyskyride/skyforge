# SkyForge

Analog instrument by [@johnnyskyride](https://x.com/johnnyskyride).

## Play in a window (no browser chrome)

This is the desktop app. One install. Double-click **SkyForge**. It is not Chrome, Safari, or Edge — it is its own window.

When you open it **online**, it pulls the latest instrument patch from this repo (knobs, haunt, sounds). When you are **offline**, it plays the last copy.

Grab the build for your machine from [Releases](https://github.com/johnnyskyride/skyforge/releases):

- Windows — `.exe` / `.msi`
- Mac — `.dmg`
- Linux — `.AppImage` / `.deb`

That is the install-once, patch-forever path.

## Play as a file

Download **SkyForge.html**. Open it in any browser, even with wifi off. Send that file to anyone.

## Ableton

SkyForge is not a VST. Arm, play, **Bounce** a WAV (or MIDI) and drop it on a track.

Halloween knobs the haunt. Presets: Init, Bass, Lead, Pad, Pluck, Keys, Haunt.

SF-33.
